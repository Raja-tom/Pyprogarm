Python Conditional Statements Practice
=======================================

This ZIP contains 20 beginner-friendly Python programs.

How to run:
1. Extract the ZIP file.
2. Open the extracted folder in VS Code.
3. Open a terminal in VS Code.
4. Run a file, for example:
   python 01_even_or_odd.py

If `python` does not work on Windows, try:
   py 01_even_or_odd.py

Notes / assumptions:
- Pass mark is assumed to be 35 out of 100.
- Voting age is assumed to be 18.
- Student discount is assumed to apply to people under 18.
- The shopping discount is 10% only when the bill exceeds 2000 (not when it equals 2000).
- February is reported as 28 or 29 days; the year is not requested.
- Scholarship requires marks >= 90 and attendance >= 85%.
